# Rock Paper Scissors - MIT App Inventor

A mobile Rock-Paper-Scissors game built using MIT App Inventor with live score tracking and a play-again feature.

## Features
- Play Rock, Paper, or Scissors against a random computer choice
- Live score tracking (wins / total rounds)
- Instant win/lose/draw result
- Play Again button resets the score

## How to Open
1. Go to MIT App Inventor
2. Click Projects → Import project (.aia) from my computer
3. Select the .aia file from this repo

## Built With
- MIT App Inventor (block-based visual programming)
